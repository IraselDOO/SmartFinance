# Smart Finance Doo — Бухгалтерский сайт в Ульцине (Черногория)

Современный одностраничный веб-сайт для бухгалтерской компании **Smart Finance Doo**, разработанный на основе фирменного стиля Hero и информационной структуры прототипа.

---

## 🚀 Особенности и стек

* **Стек:** Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS, Lucide Icons.
* **Дизайн:** 
  * Hero-секция в стиле современного финансового офиса Smart Finance с объемным логотипом на стене.
  * Фирменная благородная палитра: глубокий красный `#C01525`, золото SF `#EAA51D`, темный графит и чистый белый.
  * Карточки услуг и процесса работы строго по прототипу.
* **Каналы связи (3-в-1):**
  * **WhatsApp:** прямая ссылка `wa.me/` с приветственным текстом в один клик.
  * **Telegram:** прямая ссылка на аккаунт/канал.
  * **Email & Телефон:** кликабельные контакты.
  * **Плавающий виджет** быстрых мессенджеров для мобильных и десктопа.
* **Обработка заявок:**
  * Серверный API эндпоинт `/api/lead`
  * Мгновенное оповещение в **Telegram Bot** (при указании токена в `.env`)
  * Модальное окно «Расчет стоимости» и форма обратной связи в подвале.
* **Локация:**
  * Точный адрес офиса: `Bulevar Boško Strugar - Bulevardi Nëna Terezë, Ulcinj - Ulqin, Ulcinj Municipality 85360`
  * Интерактивная карта Ульциня.

---

## 🛠 Запуск и разработка

```bash
# Установка зависимостей (уже выполнены)
npm install

# Запуск режима разработки
npm run dev

# Сборка проекта
npm run build

# Запуск собранного проекта
npm run start
```

Сайт доступен локально: **http://localhost:3000**

---

## ⚙️ Настройка Telegram-бота для заявок

Создайте файл `.env.local` в корне проекта (или скопируйте из `.env.example`):

```env
TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_БОТА_ОТ_BOTFATHER"
TELEGRAM_CHAT_ID="ВАШ_CHAT_ID_ИЛИ_ГРУППЫ"
```

После этого любая заполненная форма на сайте будет мгновенно присылать форматированное уведомление прямо вам в Telegram со звуком!
